# Contribute to SketchGlide

Made by Karim Eldamaty. The original project source uses the MIT licence; preserve dependency notices and model/data provenance.

Open an issue in the [project](https://github.com/12kareem2323-png/karim-ink/issues) with Windows version, CPU architecture, app version and short reproduction steps. Attach a small synthetic drawing instead of private work. Report security issues through the repository's private security reporting, not a public issue containing a key or private link.

Fork the repository, edit the `windows` project, run the relevant portable checks, and open a pull request. A Windows-targeted build on macOS does not prove Windows GUI, native dependencies, physical tablet behaviour or performance. Record the computer and driver used for native checks.

Keep native file compatibility, atomic save/conflict handling, explicit cloud-send controls, DPAPI-protected credentials, bounded input validation and recoverable undo/archive behaviour. Do not commit API keys, `.env` files, real drawings, account data, generated build folders or copied proprietary drivers/installers.

All ten pen styles, themes, selection, erasing, copy/paste, saving/reopening and exports should remain usable with both a mouse and supported tablet driver input. Test pressure and tilt with actual hardware before claiming a device works.
