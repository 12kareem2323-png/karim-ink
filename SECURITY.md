# Security policy

Security fixes focus on the latest SketchGlide Test. Older previews may not receive separate fixes.

Use [GitHub private vulnerability reporting](https://github.com/12kareem2323-png/karim-ink/security/advisories/new) when available. Otherwise open a minimal issue asking for a private route, without exposing the vulnerability. Include version, impact and safe steps. Do not attach credentials or private drawings. No response time or bug bounty is promised.

Get downloads from the official [release](https://github.com/12kareem2323-png/karim-ink/releases/tag/v0.2.0-test), and compare SHA-256 hashes. Mac Test is ad hoc signed/unnotarized; Windows Test is unsigned. A checksum identifies a file; it does not replace trusted developer signing. Keep system security enabled. See [Support](SUPPORT.md).

Mac credentials use Keychain; Windows credentials use current-user DPAPI separately from drawings. Editable files and exports are ordinary local files, not encrypted vaults. Optional network routes are described in [Privacy](PRIVACY.md). Back up important work. Format/resource limits reduce risk but cannot establish that every defect has been removed. Third-party drivers/services have their own security processes.
