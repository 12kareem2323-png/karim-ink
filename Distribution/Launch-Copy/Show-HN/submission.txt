I'm Karim Eldamaty. SketchGlide is my personal whiteboard project, and the Mac and Windows 0.2 Test builds are available to download. It uses Swift/SwiftUI/AppKit/Metal on Mac and C#/WPF on Windows. Ordinary drawing and local saving need no account.

It includes adjustable brushes, a symbol library, simple 3D concept sketches and image/PDF export. The source is public. I would appreciate feedback on drawing, performance and first launch, or a focused pull request.

This is an early Test. Mac needs Apple Silicon and is unnotarized. Windows needs Windows 11 Intel/AMD x64 and is unsigned. Windows verification used x64 emulation on Windows ARM, so a physical Intel/AMD PC and real tablet checks are still needed. The site includes first-launch help and verification notes.
