First launch on your Mac

This free Test build targets Apple Silicon (ARM64) and macOS 14 or later. It has been tested on Apple Silicon with macOS 27.2. It is ad hoc signed and unnotarized, distributed outside the Mac App Store; macOS may block the first launch.

  1. Get the ZIP or DMG from the official release page, compare its SHA-256 checksum, and move SketchGlide.app into Applications.
  2. If an unidentified-developer warning appears, check that you trust the download. After trying to open it, go to System Settings → Privacy & Security, choose Open Anyway for SketchGlide where available, and confirm Open.

This is a per-app exception described in Apple’s first-launch guidance. Do not disable Gatekeeper or remove quarantine flags. If the alert says the app contains malware or is damaged, stop and report the exact message. A managed Mac may not allow an exception.

Windows Test: first launch

The Windows package targets Windows 11 on Intel / AMD x64 PCs. Extract the complete ZIP into a folder you control, then run SketchGlide.exe with its supporting files alongside it.

This Test build is unsigned and can trigger a Microsoft Defender SmartScreen warning. Check the release source and SHA-256 checksum before deciding whether to run it. Keep Windows security protections enabled. Physical Windows hardware and tablet coverage remain unverified; report your PC, tablet, driver and exact error.

Windows recognition and PDF export differ from the Mac version. Optional cloud AI uses your own OpenAI API key and separately billed usage. Local AI needs a separately installed Ollama service and model.

Quick setup checks

  • Download will not open: follow the first-launch guide above for an unidentified-developer warning. Keep macOS security protections enabled and report the exact message for other warnings.
  • Missing pressure or tilt: check your tablet's platform driver, its application profile and relevant driver permissions. The Mac app uses standard AppKit pen events; Windows uses Windows stylus input and cannot create data the driver does not provide.
  • AI will not reply: Mac local chat needs a ready Apple model; Windows local chat needs Ollama and a downloaded model. OpenAI needs internet, your own API key and separate API credit. Check the displayed route and error.
  • Recognition is wrong: DeTeXt recognizes one symbol at a time; OCR and spelling can misread engineering notation. Check numbers, units and symbols before changing the drawing.
  • Craft or Notion differs from the Mac app: Craft updating is one-way for supported basic objects. Notion uses an exported web companion. Neither embeds the native engine or offers shared editing.
