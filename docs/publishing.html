For the Mac App Store

Apple routes beta and Test builds through TestFlight. The current 0.2 Test remains a direct preview download; a production Store release needs completed features and a separate Store build.

  1. Enrol under the correct legal identity and create the App Store Connect app record.
  2. Prepare distribution signing/provisioning, adapt the app for the sandbox and make a production build. The current Xcode configuration has sandboxing disabled.
  3. Test file access, tablet features and optional integrations in that Store build.
  4. Add screenshots, privacy/support details, age rating and an accurate feature description.
  5. Review optional donation/payment links against current Store rules, submit for review and verify a fresh Store install.
