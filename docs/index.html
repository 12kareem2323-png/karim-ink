Before your first drawing

A few useful answers.

How do I open the unnotarized preview?+

This free preview has an ad hoc signature, not an Apple Developer ID signature, and has not been notarized. For a trusted download, try opening it and then use System Settings → Privacy & Security → Open Anyway for Karim Ink, if available. Keep macOS protections enabled; see the first-launch guide and Apple’s instructions.

Will my drawing tablet work?+

Karim Ink uses standard macOS AppKit pen events. Pressure, tilt, hover and eraser data can work when your tablet's macOS driver supplies them. The app is not restricted to Xencelabs, but physical operation has not been verified across Wacom, Huion, XP-Pen and every other brand. Vendor-specific remotes and buttons need their own compatible driver mapping.

Does it work offline?+

Drawing, local files, engineering tools, single-symbol recognition and local handwriting review work offline. On-device language-model chat needs a ready compatible Apple Intelligence model. OpenAI API chat, external links and Craft updates need internet.

Is ChatGPT included in the app?+

The assistant can use the OpenAI API with your own key and separately billed API usage. It does not sign into your ChatGPT subscription. Local chat needs macOS 26 or later, supported hardware and a ready Apple Intelligence model. AI is optional; normal drawing does not need an account.

Will it always run at 120 FPS?+

Metal accelerates active ink and the app limits caches and background work. A particular frame rate or latency is not guaranteed. Performance depends on your Mac, display, drawing size and active tools; very large boards and zoom rebuilds can still pause.

What about Windows and supporting the project?+

Windows is coming soon. This release is Mac-only. Visit Support development to donate with PayPal. No payment is needed to use the preview.

How can I report a bug or help improve it?+

Use the feedback page to prepare a report with your app/macOS version and reproduction steps. Do not include keys, private drawings or sensitive coursework in a public report.
