## Feature navigation draft

SketchGlide is a native Mac drawing and engineering sketching app. Core drawing, the local library and local single-symbol recognition do not require a cloud account. Create a board from Home, choose a drawing tool, and use the separate selection tool to select existing marks. The toolbar/inspector provides shapes, guides, dimensions, backgrounds and export. The symbol, maths and 3D workspaces expose their respective tools.

Local recognition produces candidates for user review; it is not a full handwritten-equation-to-LaTeX service. 3D tools provide sketch planes and primitives rather than a certified CAD solver. A drawing tablet is optional for core use; pressure/tilt require suitable hardware and driver support.

Cloud assistance uses optional user-configured OpenAI API access. Craft sync uses an optional document-scoped connection. Notion-friendly HTML export is a file exchange, not a live embedded Notion canvas. Explain the enabled final integration flows and external service requirements accurately.
