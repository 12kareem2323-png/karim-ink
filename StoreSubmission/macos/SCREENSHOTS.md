# Mac Store screenshot plan

Apple requires **at least one**, up to **10** screenshots per device size, JPEG/JPG/PNG with no alpha/transparency. For Mac apps, use a 16:10 image at **1280×800**, **1440×900**, **2560×1600** or **2880×1800**. A raw 14-inch MacBook Pro 3024×1964 capture is not one of those Store sizes. [Apple screenshot specifications](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications/)

No Store-ready screenshots are claimed by this document. Existing release QA images show the Test build and need recapture/review against the final sandboxed build. Use synthetic drawings and an isolated library, with no keys, accounts, private drawings or unrelated desktop content visible. Keep the actual controls legible and avoid stretching the UI.

Capture plan, preferably one consistent 2560×1600 layout:

1. **Draw your way:** engineering sketch, visible brush controls and uncluttered canvas.
2. **A diagram toolkit:** symbol browser and a synthetic circuit/beam diagram using actual library symbols.
3. **Maths in one workspace:** editable formula, calculator and graph from a simple worked example.
4. **Review recognition:** a genuine single-symbol candidate/OCR review screen; no full-equation recognition claim.
5. **Light and dark:** final appearance controls and the same synthetic board in the chosen theme.
6. **Explore 3D sketches:** the actual sketch planes/primitives workflow, not photorealistic CAD rendering.

Optional cloud AI screenshots must use an authorized safe test configuration and accurately show provider requirements. Do not fabricate a successful response or hide paid/configuration limits. App previews are optional; the existing promotional video is not automatically a valid Store preview. [Apple platform metadata](https://developer.apple.com/help/app-store-connect/reference/app-information/platform-version-information/)

Before submission, verify dimensions, file format, no alpha channel, no placeholder/beta branding, matching final UI/features and the right localization. Do not use unofficial App Store award badges or claimed hardware certification.
